## 3. Reflexão Crítica
A aplicação da regra `MethodName` através do Checkstyle é crucial para manter a consistência e a padronização do código-fonte em Java. Seguir a convenção `camelCase` melhora a legibilidade do projeto, permitindo que a equipa identifique rapidamente métodos e distinga chamadas de funções de tipos de classes ou constantes. A automação desta verificação via GitHub Actions funciona como um Quality Gate eficaz, prevenindo a introdução de dívida técnica e garantindo que código desalinhado com as boas práticas não chegue à branch principal.

**Nota sobre o histórico de commits:**
