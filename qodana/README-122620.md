## Reflexão (Tarefa 2A, passo 11)

O Qodana detetou 1 instância do cheiro *Long Parameter List* no projeto BattleShip2, correspondente ao método introduzido deliberadamente para teste, com 9 parâmetros acima do limiar definido de 6. Não foram encontrados falsos positivos nem falsos negativos no código original do projeto, o que sugere que o limiar de 6 parâmetros é adequado para este contexto. O resultado é sensível ao valor-limite: reduzindo o limiar para 4, surgiriam provavelmente ocorrências legítimas no código existente, aumentando os falsos positivos. Face à estratégia do livro *Object-Oriented Metrics in Practice*, a principal limitação é o uso de um limiar absoluto por inspeção, não sendo possível expressar condições compostas (AND) nem valores relativos à média e desvio-padrão do sistema.
