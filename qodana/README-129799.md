## Reflexão

O elevado número de execuções que chumbaram com 202 erros ocorreu porque o Qodana não encontrou o perfil personalizado devido a um erro no caminho configurado no ficheiro global, assumindo por padrão o perfil genérico da JetBrains com tolerância zero a falhas. Isto gerou uma sequência massiva de commits na tentativa de corrigir a sintaxe do YAML, ajustar a localização dos ficheiros no Git e forçar o motor a reconhecer as alterações, uma vez que a ferramenta não detetava modificações diretas no código Java. A validação final do Quality Gate foi concluída em dois momentos, primeiro ao injetar 70 métodos numa classe Java para forçar a violação do limite de 60 e obter a build a vermelho, e finalmente ao remover esses métodos excedentários para colocar o pipeline a verde e garantir a integração contínua com sucesso.
